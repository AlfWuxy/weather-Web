# 资源保护与高德密钥迁移

适用于 Web、小程序及后台地理编码。正式运行时既有 FEATURE_WEB_AI=0 与空密钥约束保持不变，本补丁不启用 AI。生产启用前执行包含
`0034_security_budgets` 的迁移，创建 `resource_budgets` 和 `resource_leases`。
部署脚本提前 `create_all` 时，迁移核验已有表结构后继续；结构不兼容则停止。
迁移同时清空历史 `location_cache.raw_json` 冗余响应，保留业务地点与坐标。
有预算记录时禁止删表降级，防止重置付费额度；需回滚时保留数据库并仅回滚应用代码。
缺少表、数据库不可用或额度已满时，不发出 AI / 高德付费请求。
预算支持 SQLite 和 PostgreSQL，进程重启不重置，所有 worker 共享。

## 默认额度

| 配置 | 默认值 | 含义 |
| --- | ---: | --- |
| MAX_CONTENT_LENGTH_BYTES | 1048576 | 普通入口默认 1 MiB，超限返回 413；保留机构工作台原有 2 MiB JSON / 20 MiB 内存上传边界 |
| EVENT_META_MAX_BYTES | 2048 | 埋点 meta 的 UTF-8 JSON 字节数 |
| EVENT_META_MAX_DEPTH | 5 | meta 容器和叶子节点最大层数 |
| EVENT_META_MAX_FIELDS | 64 | 所有容器的元素总数 |
| PAIR_MAX_PER_USER | 20 | 每个账号所有状态的照护绑定总量 |
| PAIR_LIST_PAGE_SIZE | 20 | Web/小程序每页绑定数，代码硬上限 50 |
| RATE_LIMIT_AI | 30 per hour | Web 新旧 AI 路由共用的正常请求频率 |
| AI_USER_DAILY_LIMIT | 60 | 每用户每日供应商调用次数，包含重试 |
| AI_DAILY_LIMIT / AI_MONTHLY_LIMIT | 300 / 5000 | 全站每日 / 每月 AI 调用次数 |
| AI_USER_DAILY_TOKEN_LIMIT | 200000 | 每用户每日保守 token 预留总量 |
| AI_DAILY_TOKEN_LIMIT / AI_MONTHLY_TOKEN_LIMIT | 1200000 / 20000000 | 全站每日 / 每月保守 token 预留总量 |
| GEOCODE_USER_DAILY_LIMIT | 20 | 每用户每日地理编码调用数 |
| GEOCODE_DAILY_LIMIT / GEOCODE_MONTHLY_LIMIT | 200 / 3000 | 全站每日 / 每月地理编码调用数 |
| GEOCODE_RESPONSE_MAX_BYTES | 65536 | 流式读取响应上限，代码硬上限 64 KiB |
| LOCATION_CACHE_MAX_ROWS | 1000 | 全站地点缓存最大行数 |

自然日/月按 UTC 切换（台北时间 08:00），数值可通过环境变量调整；0 为拒绝，
不代表无限制。频率限制仍依赖部署中的共享 Redis；付费总额保护独立依赖数据库。
固定调用量与 token 上界限制资源消耗，但不替代供应商账户的货币余额 / 预算告警。
模型价格变化时应重新核对预算对应的金额。

AI 每次请求都原子预留三种调用量与三种 token 额度。输入最多 800 字符，
完整消息 JSON 最多 32768 字节，输出硬上限 4096 token；输入 UTF-8 字节数
加 4096 模板余量再加最大输出作为保守 token 预留。最多重试两次；
超时、失败及重试也可能产生费用，因此不根据响应退款。数据库失败返回 503，额度满返回 429。

绑定创建在调用方事务内先写锁定账号，再检查总数并插入；并发创建不能越过额度。
小程序超额时新建家庭成员随同事务回滚。历史超额绑定不删除，可分页查看，
但不能继续新增。Web 使用 `?page=N`，小程序列表增加 `page` 与 `has_more` 字段。

## 地点缓存

相同地点的并发 miss 使用数据库租约合并，等待者短时等待后安全降级，不重复调用。
成功缓存最多保留 30 天，失败 / 无结果负缓存 1 小时。缓存写入原子清理过期记录，
按最近写入时间保留不超过配置上限的行；锁表使用固定 256 个散列槽，避免无限增长。
原始供应商响应不入库，日志不输出输入地址、坐标、URL、密钥及可能包含这些值的异常。
预算过期行在下一次预留时清除，最长保留约 40 天。

## 高德密钥迁移

- `AMAP_JS_API_KEY`：浏览器 JS API 专用 key，可出现在页面，需在高德限制域名。
- `AMAP_WEB_SERVICE_KEY`：只用于服务端地理编码，不向任何模板输出。
- `AMAP_SECURITY_JS_CODE`：现有 JS 安全配置，保留其当前用途。
- `AMAP_KEY`：不再读取或回退。管理员应在高德控制台核对旧 key 用途，创建或选择
  两个用途匹配的 key 后分别配置，不能把旧 key 盲目复制到两个配置项。
  两个配置使用相同非空值时应用拒绝启动，避免误配置再次把服务端 key 输出到页面。

缺浏览器 key 时地图不加载；缺服务端 key 时保留静态地点及原始坐标解析，
自由地址使用现有安全降级流程。历史曾暴露到页面的服务端 key 应由管理员在供应商端轮换。

回归验证使用临时数据库、并发线程与 mock 响应，不调用真实付费 API。
