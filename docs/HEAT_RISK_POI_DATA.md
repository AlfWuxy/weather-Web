# 工作台公开点位维护

工作台将公开村落、医疗机构与候选纳凉建筑作为独立空间图层。数据只在本地读取，不为新增点位发起天气请求，也不新增数据库社区、居民人数或天气订阅。

## 文件与职责

| 文件 | 内容 |
| --- | --- |
| `data/gis/duchang_settlements.geojson` | 公开地名库与地图中的村落、聚落点 |
| `data/gis/duchang_resources.geojson` | 已收录医疗机构与纳凉资源候选 |
| `data/gis/duchang_resource_inventory.json` | 官方列名但尚待定位或复核的机构及历史纳凉场所 |
| `scripts/gis/build_public_settlements.py` | 离线复建公开聚落数据，显式传入原始下载，不联网 |
| 对应的 `*_sources.md` | 来源、筛选、去重、精度及未解决的问题 |
| `services/heat_risk_poi_service.py` | 数据校验、空间归属、去重与收录数汇总 |

两个数据文件使用 GeoJSON FeatureCollection；坐标顺序为经度、纬度，统一为 WGS84。不得把 GCJ-02、BD-09 或未确认坐标系统的数据直接写入。转换时应保留原始来源、坐标系统和处理方法。GeoNames 的近似地名位置不是建筑入口；地图中的点位不是村界。

## 每个点的证据

使用稳定 `id`，保留 `name`、`kind`、`township_name`、`source_url`、`source_id`、`source_type`、`retrieved_at`、`coordinate_source`、`coordinate_precision`、`verification_status`。已知时记录 `source_updated_at`；下载时间不能代替数据更新时间或现场核验时间。

- `settlement`：聚落点。只有行政资料明确支持时，才将 `settlement_level` 标记为行政村或自然村；其余为 `unknown`。
- `medical`：有机构本身的位置证据。乡镇政府或驻地坐标不能代替卫生院坐标；公开列名也不能保证当前营业。
- `cooling_candidate`：可能适合纳凉的公共建筑。名称和位置不证明对公众开放、有空调或无障碍设施。
- `cooling_verified`：需要可追溯的公众纳凉开放证据、核验日期及有效期；过期记录不得继续作为已核验资源展示。

人口、老年人口比例、空调、无障碍、开放时间等未知字段保持 `null`。禁止使用统一默认值填充。公开地图不提供居民健康档案；不得将私人地址和健康信息写入公开文件。

## 收录数与空间归属

工作台按已有的 24 个乡镇边界进行空间归属。乡界数据也有版本与精度限制；空间归属不替代民政部门的行政隶属认定。缺少坐标、坐标系统未确认、跨乡边界冲突或疑似搬迁的记录，应留在待核验材料中，不强行放到地图。

官方名录与地图点位分别保存；优先使用明确的机构关联 ID；未给 ID 时，仅允许同乡且名称或明确别名唯一匹配的条目视为已定位。科室点不能仅因名称相近而消除主院的待定位记录。拟注销公示不等于已经注销，需保留待复核状态。乡镇未明确的县级机构保留在全县名录中。

乡镇对比表展示“已收录”的数量。行政村与自然聚落可能存在多对一关系，不能将聚落点数除以行政村数计算覆盖率。某乡镇没有收录医疗点，表示资料尚缺，不表示当地没有医疗机构。

旧站点仅在同乡、同名或明确别名且位置足够接近时与新点合并。不同乡镇的同名点保留独立 ID。新的公开坐标不覆盖原有村档案与人口字段。

## 风险与距离

此图层不修改已发布网格数据、静态风险评分、权重或医疗可达性模型。旧模型使用的乡镇驻地点统一解释为“可达性参考点”，不能称为真实医疗服务圈。

新增医疗距离只表示到已收录机构的直线距离，不是到全部机构的最短距离、驾车时间或实际转诊能力。近似聚落点的网格风险同样是按点位估算，不能解释为全村实际暴露。缺少网格或人口数据时应明确显示未知。疑似同名而位置未核实的聚落点保留供地图比较，但暂不进入自动巡访排序，避免同村占据多个走访名额；无静态评分网格的点也不参与该排序。

## 更新与验证

更新时先保存公开来源与抓取日期，在隔离分支替换数据文件，再检查：

1. 坐标系统、经纬度顺序、县域及乡镇归属。
2. 跨来源同名点是否重复，迁址和同名机构是否仍有歧义。
3. 来源链接、许可、记录更新时间与核验有效期。
4. 所有乡镇的收录数量变化；缺少记录的乡镇不得被隐藏。
5. 桌面和手机上的筛选、选点、来源查看以及候选资源标识。
6. 数据扩充不增加天气 API 调用，不改变已发布静态评分。

原始下载与一次性研究报告放本地归档；运行数据、来源说明和必要测试放主仓库。公开数据集保留 OpenStreetMap 与 GeoNames 署名及各自许可；来源方不为本项目的风险判断或机构开放状态背书。
