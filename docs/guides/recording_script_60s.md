# 60 秒录屏脚本（申请证据包用）

版本 1.0 · 2026-09-05 · W7 执行。全程使用 `qa_` 测试 pair 与合成数据；画面内不得出现真实姓名、电话、地址、访问量数字。录屏文件不上传公开仓库。

| 秒 | 画面 | 说明字幕（中文，右下角一行） |
|---|---|---|
| 0–8 | `/status` 页首屏：英文三行 + 一句话边界 + 四栏 | "原型，未被采用；下面演示的是可审计的行动链" |
| 8–18 | 老人短码页 `/action`（大字模式）：输入短码 → 出现三按钮 | "老人端只有三件事：看懂了 / 做到一项 / 做不到需要帮助" |
| 18–26 | 点「我看懂了」→ teach-back 单选「今天你准备先做哪一步？」→ 选一项 | "理解不是点击：让老人说出下一步" |
| 26–32 | 点「做不到，需要帮助」→ 文案"已记录，正在通知家属" | "求助真的推送给家属" |
| 32–42 | 家属端 `/caregiver/pair/<id>`：状态条亮起 help → 点「已收到求助」→ 点「结案」 | "家属确认收到、核验、结案，每一步是一条事件" |
| 42–52 | `/analysis/pilot`：带分母漏斗 delivered → … → closed，unknown 数，"描述性 / 因果 HOLD" 标签 | "分母是当日活跃配对；没点的算 unknown，不算安全" |
| 52–60 | `/cooling`：一张已核验卡片（最后核验日期 · 电话）+ 一张灰色未核验卡片 | "地图上的点只有核验过才算资源" |

录制要求：1080p、无声或仅字幕、浅色主题、浏览器无书签栏、地址栏显示 yilaoweather.org 域名。文件名 `yilao_action_chain_60s_<date>.mp4`，存证据包。
