# 埋点与导出中的隐私边界

`Pair.location_query` 是照护绑定的业务数据。埋点只保存事件、关联 ID、固定枚举、布尔值及计数；不复制地址、坐标、任意嵌套对象或异常原文。新增埋点字段必须在 `core/analytics_privacy.py` 明确用途与类型。网页事件来源由服务端固定为 `web`。

管理员 CSV 导出对所有文本列统一处理公式前缀（包括前导空白、控制字符及 BOM），同时覆盖修复前已经保存的数据。普通中文、数字、逗号、引号和换行按标准 CSV 编码保留。

上线时，在确认实际数据库与受限备份后，用应用相同环境执行：

```sh
python scripts/scrub_usage_metadata.py
python scripts/scrub_usage_metadata.py --apply
python scripts/scrub_usage_metadata.py
```

第一次只显示待清理数量；第二次分批清理历史元数据，保留允许的汇总字段；最后一次应为零。脚本不改业务地址、账号和反馈原表。执行结果只输出数量，不回显原始记录。

历史日志和旧备份不会因代码升级自动消失。发布验收还需盘点副本位置、把访问权限限制到运维身份，并按既定保留期限清理历史副本；在完成前，不得把“停止新增泄露”记为“历史副本全部清除”。
