# 维护入口的私有文件约束

快速修复、手动修复与备份入口在创建文件前设置 `umask 077`。环境维护通过 `secure_environment.py` 复用既有 `update_env_value.py` 的快照校验及原子写入：已有文件先收紧到0600，拒绝符号链接和硬链接，秘密仅走标准输入。复制恢复 `.env` 前也必须先创建0600目标。

备份继续保留 `BACKUP_RUNTIME_USER`、`runuser`、PrivateTmp 暂存、`install -m 0600` 和只读SQLite源连接。新增最终文件独占创建，归档及既有历史文件0600、备份目录0700。整个备份树必须由本次备份执行账号持有；不要求普通手动备份以root运行。托管root备份仍使用原有runuser流程读取运行账号数据库，最终目录和归档由root持有。发现其他属主、符号链接、硬链接或特殊文件会失败，不通过chmod冒充安全归属，也不自动接管未知历史归档。

本项不更改原子发布器、同步转发、运行服务、定时器、环境实际配置或数据库。生产分支原发布模板已经使用回环Gunicorn、专用运行账号及SSH严格主机校验；模板状态不等于当前服务器状态，发布前仍须核验实际服务UID、监听地址、TLS代理与公网端口隔离。环境和备份权限修复也只有在实际执行并验收后才能记为已生效。

验证使用临时目录、合成SQLite数据与runuser桩。相邻用例覆盖既有只读源连接、运行账号暂存、最终归档恢复、30天保留策略与普通执行账号行为；不会读取真实居民或医疗数据。
