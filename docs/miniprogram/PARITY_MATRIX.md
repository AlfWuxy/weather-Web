# Web 与微信小程序功能对应表

| Web 模块 | 小程序实现 | 发布边界 |
| --- | --- | --- |
| 首页天气与热风险 | 首页原生卡片、快照时间和 stale 状态 | 公开 |
| 七日天气与健康提示 | 七日预报页、逐日行动标签 | 公开 |
| 官方预警 | 预警页、无预警和不可用状态 | 公开 |
| 公开风险与行动建议 | 今日行动页、确认状态 | 公开查看，保存需登录 |
| 避暑资源 | 列表、筛选、逐次确认的端内距离排序、社区手选、原生地图打开 | 公开；用户位置不上传至本项目服务器，也不进入本项目持久存储 |
| 社区脆弱性 | 聚合社区卡片与地图，明确不等于当前天气风险 | 公开聚合数据 |
| 1 km 热暴露 GIS | 延迟加载 Canvas、图层与方法说明 | 公开聚合数据 |
| 透明度与信任网络 | 原生说明页和指标解释组件 | 公开 |
| 登录注册与跨端串联 | `wx.login`，不同 OpenID 映射到不同内部账号；网页使用用户名登录并复验密码后生成 8 位一次性绑定码 | 小程序不请求微信手机号；网页手机号由用户主动填写、未短信验证，只作待验证跨端标识，1.1.1 不能用于网页登录；相同未验证号码不阻断绑定码；绑定码 10 分钟、仅哈希、失败锁定，不提供备用 Token 输入 |
| 家庭成员与照护配对 | 老人列表、新增、编辑、预警、话术 | 登录、owner scope |
| 健康风险评估 | 五项筛查、结果与方法边界 | 登录，不作诊断 |
| 健康日记 | 列表与新增 | 登录、owner scope |
| 用药记录 | 列表、新增或删除；首版不自动送达 | 登录、owner scope |
| 行动确认、求助记录、复盘 | 原生行动闭环；求助需另行联系家人 | 登录并完成健康资料单独同意；首发安全链接仅显示停用说明 |
| 第三方消息推送 | 小程序不提供入口 | 不收集第三方推送接收标识，不承诺自动送达 |
| 用户、社区和避暑点后台 CRUD | 保留 Web 管理后台 | 强权限 |
| 原始病历 | 保留 Web 管理后台 | 禁止进入普通小程序 |
| 深度研究分析与导出 | Web 完整版，小程序展示公开摘要 | 强权限或研究使用 |

普通用户相关功能在小程序内原生实现。管理、原始医疗数据与研究导出保留 Web，是权限与隐私隔离方案。
