为什么同样 10°C 会有不同结果？

温度只是一个输入。湿度、夜间最低温、前几天温度、年龄、慢病、社区脆弱性、历史病例窗口和数据完整度都可能改变结果。 主要风险与行动结果页会同时展示本次使用的关键输入，便于逐项核对。

数据与模型版本

数据来源与计算流程

天气与空气质量

  • 实时天气和 7 天预报以和风天气（QWeather）为主要来源。
  • 部分天气展示使用 Open-Meteo 备用来源；页面标明来源、缓存状态和更新时间。
  • 健康与照护评分使用通过来源和完整性检查的天气。天气资料不足时，结果显示“天气数据待更新”。
  • 7 日预报需逐日具备有效的最高温、最低温、平均温和湿度；完整性检查通过后整组进入缓存和评分。
  • PM2.5 优先采用对应时段的直接浓度；AQI 反算需同时满足首要污染物为 PM2.5、标准版本兼容和平均时长明确。资料不足时标明“空气质量资料待补充”，评分按其余已知分项重新分配权重。

DLNM 在线链路

  • 离线模型属于 quasi-Poisson 广义线性回归，DLNM cross-basis 表达温度的非线性和滞后效应。
  • 默认配置读取 final_single_model_ar1_profile.json 中导出的温度–RR 曲线并插值。
  • {% if configured_profile.status == 'available' %} 配置曲线版本：{{ configured_profile.version or '待补充' }}；参考温度 MMT：{% if configured_profile.mmt is not none %}{{ configured_profile.mmt }}°C{% else %}待补充{% endif %}。 该配置曲线已包含累积效应，在线按温度插值。 {% elif configured_profile.status == 'disabled' %}当前配置使用本地数据与文献先验分支。 {% else %}配置曲线资料待补充。{% endif %}
  • MMT 边界诊断：{% if configured_profile.mmt_boundary_flag is defined and configured_profile.mmt_boundary_flag == 1 %}参考温度位于搜索边界，需复核曲线。{% elif configured_profile.mmt_boundary_flag is defined and configured_profile.mmt_boundary_flag == 0 %}参考温度位于搜索范围内。{% else %}诊断资料待补充。{% endif %}模型状态：研究评估中；冷端 RR 1.45 与热夜 RR 1.34 保存在研究资料中。
  • 随代码发布的默认曲线采用单日 RR 上限 2.6，文献先验分支单日上限为 2.2；累计上限均为 3.5。
  • 模型未训练时使用 RR=1+0.015×|T−20| 的简化分支，并跳过病种与年龄修正；结果明细会标记该分支。

健康与社区数据

  • 历史模型数据覆盖 2023-12-13 至 2025-01-30，共 2,258 条门诊记录；60 岁以上 1,213 条。
  • 完整社区画像需具备人口、老龄率、慢病率、绿地率、热岛指数、医疗可达性、基线门诊量、基线统计天数八个数值字段，以及全体居民的基线人口口径。
  • 程序检查字段完整性、有限数、取值范围、代理值标记与基线人口和时间口径。符合要求的社区参与画像计算；其余社区显示具体资料缺项。
  • 外部汇总输入还核对社区名称、来源信息和审核日期格式。原始资料的真实性、统计覆盖、单位及实际观察时间，由资料审核确认。
  • 社区画像资料不足时，页面可展示通过校验的历史 GIS 数据，用于比较社区基础条件。两类结果各自标明数据来源与计算方式。
  • 社区热脆弱性对比使用三个等权主题：ASPECT 2020 年 65 岁及以上人口估计占比、NASA 2020–2024 年夏季晴空地表温度、ESA 2020 年低树木覆盖。
  • 这三个指标分别描述人口空间分布估计、历史地表热环境和树木覆盖类面积占比；结果为县内相对比较。
  • Q3 观测覆盖率描述有效晴空观测数量，用于检查数据质量。
  • 病例覆盖率表示社区字段的成功匹配比例；诊断编码质量另行核查。

RandomForest 分类器

  • 模型为 13 类疾病多分类器，输入包括年龄、性别、时间和天气特征。
  • 当前状态：研究存档。生产预测已停用。
  • 已记录成绩：训练集准确率 65.3%。待完成：时间外测试、同结局基线对照和独立审核。
适用范围与验证计划

后续验证工作

  • 温度–RR 曲线：完成按时间切分的回测、残差自相关检查与校准。
  • 研究版 v1 DLNM 曲线：复核报告中的 MMT 搜索边界问题，再评估版本替换。
  • 社区资料：统一比例单位，补充绿地、热岛、慢病率和医疗可达性的实测记录。
  • 照护与天气关注分：核验人工规则权重与实际结果的关系。个人患病概率、门诊高负荷概率及相关模型预警的启用条件为相应结局的时间外验证与概率校准；当前状态为停用。官方天气预警独立展示。
  • 慢病评分：年龄放大规则在慢病层应用一次，下一步使用真实试点数据校准。
  • 数据状态：结果同时标明缺失项、插补方法、模型分支及天气更新时间。
隐私与资料管理

系统会保存什么

  • 注册与照护功能会在账号权限范围内保存用户名、家庭成员档案、健康字段、评估记录和行动记录。
  • 短码和行动令牌使用哈希与有效期保护；健康档案在对应账号权限范围内访问。
  • 个人阈值拨片保存在当前浏览器。
  • 公开的历史建模报告使用去标识或聚合数据。
  • 微信小程序不使用第三方生成式 AI，也不会把老人档案、健康记录或自由文本发送给 AI 服务。
  • Web 正式入口的 AI 问答当前关闭；如未来启用，会在发送前单独说明处理方、数据用途、保存期限并取得明确同意。
  • 医生试点的准备工作包括角色权限、共享授权、审计和必要字段范围。
